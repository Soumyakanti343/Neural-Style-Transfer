FAQs

The style-transfer decoder is trained by me using the AdaIN-based neural style transfer approach.

The system extracts content and style features using a VGG encoder, combines them using Adaptive Instance Normalization (AdaIN), and generates the final artistic image using a trained decoder.

You can use almost any artistic image as a style reference, including impressionism, abstract art, cubism, watercolor, sketch and more.

Python, PyTorch, TorchVision, Flask, HTML, CSS and JavaScript are used in this project.
